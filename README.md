# daily-challenge-calendar

## Beskrivelse
Daily Challenge Kalender er en applikasjon der brukere kan lage og dele daglige utfordringer knyttet til en kalender. Brukere kan gi hverandre utfordringer, fullføre dem og følge progresjonen.

## Feature Map
- Brukerregistrering og innlogging
- Opprette daglige utfordringer
- Gi utfordringer til venner
- Kalendervisning
- Fullføre utfordringer
- Progresjon og historikk
- Offline støtte
- PWA støtte

## Teknologi
- Client: Web app (PWA)
- Server: REST-aktig API
- Database: PostgreSQL
